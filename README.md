# Chapin High School Robotics

The published files for https://chapin-robotics.github.io, the sponsor page for
Chapin High School's VEX V5RC robotics teams in El Paso, Texas.

This repo only holds the built site. It is updated automatically, so changes
made here by hand get overwritten on the next deploy.
